HOW IT WORKS
  Save each clip with the EXACT file name below. The website plays it
  automatically. If a file is missing, the page shows its drawn fallback instead,
  so you can add clips one at a time.

  - Hero (top of page):  public/assets/hero.mp4
  - Story chapters:      public/assets/story/01.mp4 ... public/assets/story/12.mp4

FILE SPECS (keeps the site fast)
  - Format: MP4 (H.264), landscape, no audio needed
  - Length: 8-20 seconds (they loop)
  - Size: hero under 8 MB, each story clip under 4 MB

COMPRESS WITH FFMPEG (optional, if a file is too big)
  ffmpeg -i input.mp4 -vf scale=1280:-2 -an -c:v libx264 -crf 28 -preset slow -movflags +faststart output.mp4

NOTE: stock footage is generic and will not show SSR's actual mill. If you can
film your own clips on a phone (landscape, steady, good light) at the mill -
the yard, the machines, the bags - use those instead for the same file names.
